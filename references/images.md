## How to use it

- **The user's image wins.** A URL, a file or a `.pen` image the user supplied is never
  replaced. This catalogue is for the case where nobody said which picture to use.
- **Choose by subject, not by the nearest row.** A hero wants a wide landscape, a
  feature card an object, an avatar a face, a testimonial one person.
- **Copy the `src` whole.** `?w=1080&q=80&fm=jpg` is part of the URL that was verified.
  The `&` needs no escaping in the fragment you hand to `add`; the file is written with
  `&amp;`.
- **A small avatar may ask for less:** change `w=1080` to `w=400` and leave the rest
  of the URL alone.
- **The credit goes in `data-credit`.** It never renders. The Licence does not require
  it; keeping it makes a photo findable again the day the URL breaks.
- **No photo fits?** A solid colour or a linear gradient is the honest placeholder.
  Never invent a `photo-…` id: a URL that resolves to nothing renders an empty box,
  which is worse than a placeholder nobody mistakes for a photograph.

- **Reselling or compiling.** You cannot sell unmodified copies, and you cannot build a

- **Unsplash+.** Its paid photos are a different licence. None are in this file.
- **People and trademarks.** The faces above belong to real people with rights of
  publicity; the object photos may show a brand. A stock face in an avatar or a mockup
  is ordinary use. A shipped page that presents one as a real customer's testimonial,
  or a logo as your product, is not covered by the photo licence.

The images are **hotlinked**, never copied into the repository: the design file stays
text, and the photos render only while there is a connection. A photo its author
deletes stops resolving, so run `npm run images:check` before a release that depends
on them; it prints every URL that no longer resolves.

A credit reads `Photo by <name> on Unsplash` when the photographer's name was recorded
(the photos inherited from `examples/miniprogram.pen`), and `Photo from Unsplash` when
it was not. The licence does not require attribution, so either one is a complete
credit; the first is simply easier to trace.
